Política de Privacidade

Conteúdo Kardec — última atualização: 16 de setembro de 2026

Resumo

O app do Conteúdo Kardec não coleta, armazena nem compartilha dados pessoais de usuários do TikTok ou do YouTube/Google. Ele é uma ferramenta de publicação de conteúdo, usada apenas pela responsável pelo projeto para postar vídeos nas contas oficiais do Conteúdo Kardec.

Quais dados o app usa (TikTok)

O app usa a Content Posting API do TikTok somente para enviar vídeos (arquivo de vídeo, legenda e configurações de privacidade da postagem) para a conta do próprio projeto. Não coleta dados de espectadores, seguidores ou de qualquer outro usuário do TikTok. Não acessa listas de contatos, mensagens privadas, nem qualquer informação de perfil além do necessário para autenticar e publicar na conta autorizada.

Quais dados o app usa (YouTube/Google)

O app usa a YouTube Data API v3, com o escopo youtube.upload (o mínimo necessário só para enviar vídeo — não pede acesso a comentários, mensagens, analytics ou à lista de contatos do Google). Ele é usado exclusivamente para enviar vídeos (arquivo, título, descrição e nível de privacidade) para o canal do próprio projeto no YouTube, operado pela responsável pelo projeto. Não coleta, processa nem armazena dados de espectadores, inscritos ou de qualquer outro usuário do YouTube ou do Google. O uso de qualquer informação recebida das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado ("Limited Use").

Como as credenciais são guardadas

Os tokens de acesso (OAuth) usados para publicar — tanto do TikTok quanto do YouTube/Google — são armazenados apenas localmente, no computador da responsável pelo projeto, nunca em servidores de terceiros nem compartilhado com mais ninguém.

Compartilhamento com terceiros

Nenhum dado é vendido, alugado ou compartilhado com terceiros. O único destino dos dados enviados a cada API é a própria rede correspondente (TikTok ou YouTube/Google), para publicar o conteúdo nas contas oficiais do Conteúdo Kardec.
