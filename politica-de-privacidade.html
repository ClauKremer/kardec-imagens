Política de Privacidade

Conteúdo Kardec — última atualização: 12 de setembro de 2026

Resumo

O app do Conteúdo Kardec não coleta, armazena nem compartilha dados pessoais de usuários do TikTok. Ele é uma ferramenta de publicação de conteúdo, usada apenas pela responsável pelo projeto para postar vídeos na conta oficial do Conteúdo Kardec.

Quais dados o app usa

O app usa a Content Posting API do TikTok somente para enviar vídeos (arquivo de vídeo, legenda e configurações de privacidade da postagem) para a conta do próprio projeto. Não coleta dados de espectadores, seguidores ou de qualquer outro usuário do TikTok. Não acessa listas de contatos, mensagens privadas, nem qualquer informação de perfil além do necessário para autenticar e publicar na conta autorizada.

Como as credenciais são guardadas

O token de acesso (OAuth) usado para publicar é armazenado apenas localmente, no computador da responsável pelo projeto, nunca em servidores de terceiros nem compartilhado com mais ninguém.

Compartilhamento com terceiros

Nenhum dado é vendido, alugado ou compartilhado com terceiros. O único destino dos dados enviados à API é o próprio TikTok, para publicar o conteúdo na conta do Conteúdo Kardec.
