O que é o Conteúdo Kardec

Conteúdo Kardec é um projeto pessoal, sem fins comerciais, de divulgação das obras de Allan Kardec (fundador da doutrina espírita). Publica, em português, francês, inglês e espanhol, trechos das obras de Kardec em imagens e vídeos narrados, sempre citando a fonte exata (livro, capítulo e item).

Uso da API do TikTok

Este app usa a Content Posting API do TikTok exclusivamente para publicar vídeos na conta oficial do projeto, operada e controlada diretamente pela responsável pelo projeto. O app não gerencia contas de terceiros, não oferece esse serviço a outras pessoas ou empresas, e não interage com o público em nome de outros usuários.

Uso da API do YouTube (Google)

Este app usa a YouTube Data API v3 exclusivamente para publicar vídeos no canal oficial do projeto, operado e controlado diretamente pela responsável pelo projeto. Não gerencia canais de terceiros, não oferece esse serviço a outras pessoas ou empresas, e não interage com o público em nome de outros usuários. O uso da API segue os Termos de Serviço da API do YouTube.

Conteúdo publicado

Todo o conteúdo publicado consiste em citações literais das obras de Allan Kardec (a maior parte em domínio público), com narração em áudio e referência bibliográfica completa. Nenhum comentário ou interpretação é apresentado como sendo texto original de Kardec. Quando uma tradução com direitos reservados é usada, isso é sempre citado de forma transparente.

Responsabilidade

O conteúdo é de natureza religiosa e educacional, refletindo a doutrina espírita conforme sistematizada por Allan Kardec. A responsável pelo projeto se compromete a manter a fidelidade às fontes originais e a corrigir qualquer erro apontado.
